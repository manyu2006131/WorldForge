# 世界工坊 WorldForge — 第一阶段开发预览

这是尚未经过 Windows 实机验收的第一阶段开发版本，包含地图基本绘制、人物档案、基础关系连线及本地项目保存。它不是三阶段完整版。

## Windows 启动

若提供了 exe，在 Windows 10/11 上直接打开便携版 exe；无需安装服务或登录。第一次从网络下载后 Windows 可能显示来源提示。项目需自行选择一个有写入权限的空文件夹。

源码运行：准备 Node.js 22 或更新版本（可使用免安装的 Windows 版 Node，确保 node 和 npm 在 PATH 中），双击“启动开发版.bat”。首次执行 npm install 要联网下载依赖，此后软件运行与项目数据保存不需要联网。双击“构建Windows便携版.bat”尝试生成 release 中的 exe；缓存、依赖和产物保存在源码目录。具体运行环境或杀毒软件可能影响构建。

## 尝试第一阶段流程

1. 新建项目，选择空目录。在地图右侧导入图片作为底图。
2. 选择画笔拖动绘制路线；选择文字或图钉并单击地图添加内容。可调整右侧颜色、粗细及透明度。
3. 进入人物，新建两个角色、填写信息；进入关系图，在右侧选定两个人物并输入关系，点击创建。拖动人物节点改变位置。
4. 等待显示“已保存”，关闭后重新打开项目文件夹，检查地图、人物和关系。

地图与关系图支持滚轮缩放，按空格拖动画布；地图切换到“选择”可拖动形状，按 Delete 删除。自动保存防抖 3 秒；退出时会尝试先保存，保存失败不会主动退出。项目中的 project.json、assets 和 backups 请一起保留并备份。最近打开路径由 Electron 本地用户设置记录。

当前未实现：撤销重做、图层、子地图、地点与角色联动、关系图双击进入档案、PNG/JSON 导出、示例项目、崩溃恢复界面等第二三阶段功能；地点档案、圆形/多边形/直线等完整功能也尚未实现。自动保存后保留最近 20 份自动备份，但没有自动恢复界面，可在关闭软件后手动把备份文件复制并改名为 project.json；操作前先复制整个项目文件夹。角色图片封面暂为居中方形显示，尚无交互式裁剪。

当前没有 iOS 版本、IPA 或 GitHub 发布记录。Electron 桌面程序不能直接运行于 iOS；iOS 必须另行适配、构建并签名。图标为个人项目生成的角色同人图，公开发布前请自行确认相关权利。
